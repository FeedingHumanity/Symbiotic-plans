# MoonBaseAlpha Systems Architecture Manual
## Version: 9.2 (Integrated Design Baseline)

The unified framework integrates the StarCatcher orbital harvesting tier into the baseline lunar expansion infrastructure, maintaining six core symbiotic legs. 

### 1. Functional System Framework
*   **Leg 0 (StarCatcher Operations):** Governs orbital debris harvesting via specialized vehicles. Platform 1 handles high-cadence debris collection using smart-guided nets, while Platform 2 executes structural towing of heavy station feedstock.
*   **Subsurface Infrastructure:** Employs modular tunneling engines to excavate shielded volumes, regulated by low-latency networks linking human operators with edge robotics.
*   **Thermal Circulation Array:** Implements a Segmented Tri-Leg Topology cross-dimensioned to absorb peak thermal loads during localized line interruptions.

### 2. Leg 2 Pyrolysis & Recovery Equations
Resource reclamation converts organic inputs ($C_nH_mO_xN_y$) into solid, liquid, and gas phases under strict anaerobic mass constraints:

$$Y_{\text{Char}} + Y_{\text{Tar}} + Y_{\text{Gas}} = 1.000$$

Exothermic thermal energy is captured via the primary fluid lines, recycling heat back into incoming processing loops to minimize total grid overhead.
